## [1.0.0] - 2026-09-26

### Añadido
- Implementación de `sumaRecursiva()` para control de stack de llamadas.
- Algoritmo de búsqueda secuencial optimizado con ruptura anticipada (`break`).
- Función de intercambio de memoria (`intercambiarValores()`) utilizando punteros y desreferenciación.
- Documentación técnica `README.md` con traza de memoria RAM en formato ASCII.
